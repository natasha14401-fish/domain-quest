# Domain Quest

Учебное веб-приложение для дисциплины **«Проектирование и дизайн информационных систем»**.

Игра-исследование предметной области: интервью со стейкхолдером, ответы на вопросы системы, сбор фактов и экспорт описания предметной области (Markdown) — как заготовки для use case, ER/классов и процессов.

## Возможности

- 4 сценария: библиотека, поликлиника, интернет-магазин, общежитие
- Режим **аналитика** — задаёте вопросы, открываете факты
- Режим **стейкхолдера** — отвечаете на структурированное интервью
- Режим **полного цикла** — оба подхода с переключением
- Карта знаний по темам: акторы, процессы, данные, правила, проблемы, цели
- Экспорт описания в `.md` (копирование / скачивание)
- Статическая сборка — публикация на **GitHub Pages** без хостинга

## Локальный запуск

Нужны Node.js 18+ и npm.

```bash
npm install
npm run dev
```

Сборка:

```bash
npm run build
npm run preview
```

Готовые файлы появятся в папке `dist/`.

## Публикация на GitHub Pages

1. Создайте репозиторий на GitHub и загрузите проект.
2. В `vite.config.js` при необходимости укажите `base: '/ИМЯ-РЕПОЗИТОРИЯ/'`  
   (сейчас стоит `base: './'` — обычно достаточно для Pages).
3. В репозитории: **Settings → Pages → Source: GitHub Actions**.
4. После push в `main` workflow `.github/workflows/deploy.yml` соберёт и опубликует сайт.

Либо вручную:

```bash
npm run build
```

и укажите папку `dist` как источник Pages (Deploy from a branch / docs), либо используйте Action выше.

## Для отчёта по дисциплине

Экспортированное описание можно использовать как:

- вход для диаграмм вариантов использования;
- основу ER / диаграммы классов;
- as-is / to-be для activity / BPMN;
- черновик функциональных требований.

Прогресс и черновики сохраняются в `localStorage` браузера.
